# CHANGELOG

このリポジトリは npm workspaces のモノレポで、**変更履歴はパッケージごとに**
[changesets](https://github.com/changesets/changesets) が生成します。ルートの
`cosense-site-kit` は `private: true` で公開されないため、ここは各パッケージへの索引です。

| パッケージ | 変更履歴 | npm |
|---|---|---|
| `@cosense-site-kit/core` | [packages/core/CHANGELOG.md](packages/core/CHANGELOG.md) | [npm](https://www.npmjs.com/package/@cosense-site-kit/core) |
| `@cosense-site-kit/astro` | [packages/astro/CHANGELOG.md](packages/astro/CHANGELOG.md) | [npm](https://www.npmjs.com/package/@cosense-site-kit/astro) |
| `@cosense-site-kit/theme-utils` | [packages/theme-utils/CHANGELOG.md](packages/theme-utils/CHANGELOG.md) | [npm](https://www.npmjs.com/package/@cosense-site-kit/theme-utils) |
| `@cosense-site-kit/theme-default` | [packages/theme-default/CHANGELOG.md](packages/theme-default/CHANGELOG.md) | [npm](https://www.npmjs.com/package/@cosense-site-kit/theme-default) |
| `@cosense-site-kit/cli` | [packages/cli/CHANGELOG.md](packages/cli/CHANGELOG.md) | [npm](https://www.npmjs.com/package/@cosense-site-kit/cli) |

リリース済みバージョンは [GitHub Releases](https://github.com/shinyaoguri/cosense-site-kit/releases)
と git タグでも辿れます。

変更履歴への載せ方（changeset の付け方・bump 種別の指針）は
[CONTRIBUTING.md](CONTRIBUTING.md#リリース--npm-公開フローchangesets) を参照してください。
