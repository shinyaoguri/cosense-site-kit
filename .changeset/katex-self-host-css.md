fix(theme-utils): self-host KaTeX CSS so it can't drift from the installed katex

`KaTeXLink.astro` linked a hardcoded CDN stylesheet (`katex@0.16.11` + SRI) while
the SSR math markup is generated by the installed `katex@0.17.0`. KaTeX requires
the CSS to match the markup version, so the mismatch could break rendering — and
the SRI meant the CSS never self-corrected. Worse, the pinned version string was
structurally guaranteed to drift on every dependabot bump.

The component now imports `katex/dist/katex.min.css` from the installed package,
so Astro bundles the exact-matching version (with fonts, and offline-capable)
instead of hot-linking a CDN. Adds a test asserting the component self-hosts and
carries no pinned CDN `katex@<version>` URL.
